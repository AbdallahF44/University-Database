# University Database System

A relational database project designed to manage university data, including students, instructors, courses, and enrollments.

## Project Overview

This project focuses on designing and implementing a relational database system using **PostgreSQL**. It includes database creation, table relationships, constraints, sample data, and SQL queries for retrieving and analyzing university information.

## Database Features

* Students management
* Instructors management
* Courses management
* Course enrollment system
* Primary and foreign key relationships
* Data integrity constraints
* Sample university data
* SQL queries for data retrieval and analysis

## Database Structure

The database consists of several related tables:

* **Students** — Stores student information.
* **Instructors** — Stores instructor information.
* **Courses** — Stores course information and instructor relationships.
* **Enrollments** — Manages student enrollment in courses.

## Files

* `schema.sql` — Creates the database structure, tables, relationships, and constraints.
* `insert_data.sql` — Inserts sample data into the database.
* `queries.sql` — Contains SQL queries for retrieving and analyzing data.

## Technologies Used

* PostgreSQL
* SQL
* pgAdmin

## How to Run

1. Install **PostgreSQL** and **pgAdmin**.
2. Create a new database in PostgreSQL.
3. Open `schema.sql` and execute it to create the database tables and relationships.
4. Execute `insert_data.sql` to add sample records.
5. Run the queries in `queries.sql` to retrieve and analyze the data.
