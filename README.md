# University Database System

A relational database project designed to manage university data including students, instructors, courses, and enrollments.

## Project Overview

This project focuses on designing and implementing a database system using SQL. It includes database creation, table relationships, constraints, sample data, and queries for retrieving useful information.

## Database Features

- Students management
- Instructors management
- Courses management
- Course enrollment system
- Primary and foreign key relationships
- Data integrity constraints
- SQL queries for different use cases

## Files

- `schema.sql` - Creates the database structure and tables.
- `insert_data.sql` - Adds sample data into the tables.
- `queries.sql` - Contains SQL queries for retrieving and analyzing data.

## Technologies Used

- SQL
- MySQL

## How to Run

1. Open MySQL Workbench.
2. Run `schema.sql` to create the database.
3. Execute `insert_data.sql` to add sample records.
4. Run queries from `queries.sql`.
